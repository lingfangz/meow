## Key Guidelines for AI Assistants

1. **Read before editing** — Always read a file before modifying it
2. **Minimal changes** — Only change what is asked; do not refactor surrounding code
3. **No speculative abstractions** — Do not add features, utilities, or error handling beyond what is requested
4. **Security first** — Avoid introducing vulnerabilities (injection, XSS, etc.)
5. **Test your changes** — Run the project's test suite after making changes
6. **Preserve conventions** — Match the existing code style and patterns in the project
